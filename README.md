# 🐾 PET BOUTIQUE - Estilo e Elegância para Cães e Gatos

> [!NOTE]
> **Projeto de Portfólio:** Este repositório foi desenvolvido como um projeto prático de avaliação para o curso de Desenvolvimento Web da [DevMedia](https://devmedia.com.br). O código original passou por um processo de refatoração para aplicar as melhores práticas do mercado, como arquitetura modular e semântica avançada.

Landing page institucional de alto padrão desenvolvida com foco em conversão direta, arquitetura CSS modular e total responsividade para o pet shop Pet Boutique. O sistema aplica conceitos avançados de estruturação semântica, controle de imagens de fundo e otimização de conversão via "conversa em um clique" do WhatsApp.

## 🚀 Stack Tecnológica e Conceitos Aplicados

O projeto foi construído utilizando tecnologias fundamentais da web, focando em práticas modernas de arquitetura front-end:

- **HTML5 Semântico:** Uso rigoroso de tags como `header`, `section`, `main` e `footer` para melhorar a acessibilidade e o SEO.
- **CSS Modular (Arquitetura Nativa):** Divisão estrita de responsabilidades em arquivos isolados (`global.css`, `home.css`, `home-responsive.css`) unificados através de um arquivo mestre (`main.css`) usando a regra `@import`.
- **Layout Moderno e Híbrido:**
  - **CSS Grid Layout:** Utilizado para criar o mosaico simétrico de 12 parceiros na seção de marcas.
  - **Flexbox:** Aplicado para alinhamentos dinâmicos na seção de serviços e cabeçalho.
- **Design Responsivo:** Implementação de Media Queries para garantir compatibilidade perfeita entre celulares, tablets e desktops.

## 📝 Funcionalidades em Destaque

- **Conversa em um clique:** Integração direta com a API do WhatsApp para início de diálogo automático.
- **Geolocalização:** Mapa interativo do Google Maps com moldura institucional personalizada e carregamento otimizado (`lazy loading`).
- **Micro-interações:** Efeitos de destaque (`hover`) com transições suaves e filtros de escala de cinza (`grayscale`) para harmonia visual.
- **Pixel-Perfection:** Sincronização milimétrica com o protótipo oficial, respeitando a identidade visual da marca.
